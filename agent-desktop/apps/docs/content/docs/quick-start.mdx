This run drives Notepad on Windows: check the install, map the app, find the editor, write text into it, confirm the value changed, and clear it. Every output below is real, trimmed where noted.

Start Notepad (`notepad.exe`) in your desktop session, and run the commands from a terminal in the same session. Use an app name that `list-apps` prints (for example `notepad.exe`), and expect different refs. In PowerShell, quote every ref (`'@s2jmdx3amedsce:e1'`); see [Windows](/desktop/platforms/windows#use-powershell).

## 1. Check the install

```bash
agent-desktop status                 # permissions, supported_surfaces, state_root
agent-desktop skills get platform    # the guide for this OS, in data.content
```

`data.permissions.accessibility.state` should be `granted`, and `data.supported_surfaces` should not be empty. Agents load the platform skill before their first action; see [Skills](/desktop/skills).

## 2. Map the app

A skeleton snapshot reads three levels and marks each cut branch with `children_count`:

```bash
agent-desktop snapshot --app notepad.exe --skeleton -i --compact
```

```json
{
  "version": "2.6",
  "ok": true,
  "command": "snapshot",
  "data": {
    "app": "notepad.exe",
    "complete": true,
    "ref_count": 17,
    "snapshot_id": "s2jmdx3amedsce",
    "tree": {
      "role": "window",
      "name": "Untitled - Notepad",
      "children": [
        { "children_count": 2, "ref_id": "@s2jmdx3amedsce:e1", "name": "Text editor", "role": "textfield" },
        { "children_count": 4, "ref_id": "@s2jmdx3amedsce:e8", "role": "group" }
      ]
    }
  }
}
```

The tree is trimmed to the editor and the title bar. `e1` is the editor and `e8` is the title bar. Every ref carries its snapshot id; pass it to later commands exactly as printed.

## 3. Find the editor

```bash
agent-desktop find --app notepad.exe --role textfield --first
```

```json
{
  "version": "2.6",
  "ok": true,
  "command": "find",
  "data": {
    "match": {
      "interactive": true,
      "name": "Text editor",
      "path": ["window:Untitled - Notepad"],
      "ref_id": "@s130xb68qxnjxe:e1",
      "role": "textfield",
      "states": ["focused"],
      "value": null
    },
    "snapshot_id": "s130xb68qxnjxe"
  }
}
```

`find` saved its own snapshot, so its ref has a new snapshot id. Use the ref from your own output. How searches and refs work is in [Snapshots and refs](/desktop/snapshots-and-refs).

## 4. Write into the editor

```bash
agent-desktop set-value @s130xb68qxnjxe:e1 "hello from agent-desktop"
```

```json
{
  "version": "2.6",
  "ok": true,
  "command": "set-value",
  "data": {
    "action": "set-value",
    "details": {
      "application_commit": "not_verified",
      "auto_wait": {
        "lease_contention_count": 0,
        "lease_hold_ms": 71,
        "read_only_preflight_attempts": 1,
        "read_only_resolve_attempts": 1
      },
      "verification_scope": "element_value"
    },
    "disposition": { "delivery": "delivered_verified", "retry": "unsafe" },
    "post_state": { "enabled": true, "offscreen": false, "role": "textfield", "states": ["focused"], "value": "hello from agent-desktop" },
    "steps": [{ "label": "ValuePattern.SetValue", "mechanism": "semantic_api", "outcome": "succeeded", "verified": true }]
  }
}
```

The write went through the accessibility value pattern, without moving the cursor. `delivered_verified` means the element read back the value; it does not prove the app committed it, and `retry: unsafe` means a repeat could apply it twice. See [JSON output](/desktop/json-output#action-results-and-disposition).

## 5. Verify

The app updates its content asynchronously, so wait for the value instead of reading once or sleeping:

```bash
agent-desktop wait --element @s130xb68qxnjxe:e1 --predicate value --value "hello from agent-desktop" --timeout 5000
```

```json
{
  "version": "2.6",
  "ok": true,
  "command": "wait",
  "data": {
    "elapsed_ms": 68,
    "found": true,
    "observed": { "expected_chars": 24, "matched": true, "value_chars": 24, "value_present": true },
    "predicate": "value",
    "ref": "@s130xb68qxnjxe:e1"
  }
}
```

A read taken immediately after the write can still show the old value, which is why the verify step waits. See [Waiting without sleeps](/desktop/guides/waiting).

## 6. Restore the state

Empty the editor so the app is as you found it:

```bash
agent-desktop clear @s130xb68qxnjxe:e1
```

The result has the same shape as `set-value`, with `post_state.value` set to `""`.
