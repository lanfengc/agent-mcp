Vercel Sandbox runs a hosted microVM, created and driven with the Vercel SDK. The [`agent-desktop sandbox` commands](/desktop/sandboxes) do not manage it.

agent-desktop is a Windows binary that drives Windows apps through UI Automation in the interactive desktop session of a signed-in user. A microVM has no Windows desktop and no UI Automation, so agent-desktop cannot run against apps inside Vercel Sandbox.

## What to use instead

- **A Windows virtual machine** with a signed-in session. The [Windows requirements](/desktop/platforms/windows#requirements) list what the adapter needs.
- **The host desktop**, when the agent already runs in the signed-in Windows session.

The [Docker containers](/desktop/guides/docker-container) page covers the same limit for containers. To embed agent-desktop in a process instead, see the [C library](/desktop/ffi).
